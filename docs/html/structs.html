ClassFile src/lib/types/class_file/dot_class.h
Representa um arquivo .class completamente decodificado. É a estrutura raiz que agrega todos os componentes: cabeçalho, constant pool, flags de acesso, campos, métodos, atributos e um ponteiro para a superclasse carregada em runtime.
CampoTipoDescrição
magicu4Número mágico do arquivo .class (deve ser 0xCAFEBABE)
minor_versionu2Versão menor do formato .class
major_versionu2Versão maior (ex: 52 = Java 8)
constant_pool_countu2Número de entradas no constant pool + 1
constant_poolcp_info *Array de entradas do constant pool (índices 1..count-1)
access_flagsu2Flags de acesso da classe (ACC_PUBLIC, ACC_ABSTRACT, etc.)
this_classu2Índice no CP para a entrada CONSTANT_Class desta classe
super_classu2Índice no CP para a superclasse (0 se java/lang/Object)
interfaces_countu2Número de interfaces implementadas
interfacesu2 *Array de índices no CP para cada interface
fields_countu2Número de campos da classe
fieldsfield_info *Array de estruturas field_info
methods_countu2Número de métodos da classe
methodsmethod_info *Array de estruturas method_info
attributes_countu2Número de atributos de nível de classe
attributesattribute_info *Array de atributos genéricos (SourceFile, InnerClasses, etc.)
super_class_fileClassFile *Ponteiro para o ClassFile da superclasse; NULL se não houver ou for nativa
Usado por: loader.c dot_class.c interpreter.c basic_ops.c heap.c method_invoke.c

Frame src/lib/interpreter/basic_ops.h
Frame de ativação JVM. Cada chamada de método cria um Frame com sua própria pilha de operandos, variáveis locais, ponteiro para o bytecode e um PC (program counter).
CampoTipoDescrição
pilhaSlot[64]Pilha de operandos (máximo 64 slots)
topointÍndice do topo da pilha (-1 = vazia)
locaisSlot[64]Variáveis locais (inclui parâmetros e 'this' em [0])
codigou1 *Ponteiro para o bytecode do método
tamanhou4Comprimento total do bytecode
pcu4Program Counter: posição da próxima instrução
