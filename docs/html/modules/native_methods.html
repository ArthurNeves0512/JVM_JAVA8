native_methods.c native_methods

Registro e despacho de métodos nativos Java simulados em C.
Papel no projeto

Implementa uma tabela de métodos nativos (max 128 entradas) que mapeia triplos (classe, método, descritor) para funções C. Cada função nativa desempilha os argumentos do Frame chamador e empilha o valor de retorno quando aplicável. O StringBuilder usa o campo native_data do HeapObject para acumular a string.

Funções
initNativeMethods() linha 397
void initNativeMethods(void)

Registra todos os métodos nativos suportados na tabela estática interna. Cobre: PrintStream.print/println (int, String, boolean, char, long, float, double, Object), StringBuilder.<init>/append (todos tipos)/toString, String.valueOf (todos tipos), String.length e Object.<init>. Idempotente: ignora chamadas repetidas.

Retorno: void

NativeFn lookupNative(const char *class_name, const char *method_name, const char *descriptor)

Busca linearmente na tabela de métodos nativos e retorna o handler NativeFn para o triplo (classe, método, descritor). Retorna NULL se não encontrado.

int isNativeClass(const char *class_name)

Verifica se um nome de classe pertence ao conjunto de classes tratadas nativamente: java/lang/Object, java/lang/StringBuilder, java/lang/String, java/io/PrintStream. Usado pelo opcode new para não tentar carregar ClassFiles inexistentes.
