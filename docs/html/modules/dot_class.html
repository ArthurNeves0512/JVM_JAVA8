dot_class.c types

Alocação e liberação da estrutura raiz ClassFile
Papel no projeto

Define e implementa o gerenciamento de memória da estrutura ClassFile, que é a representação raiz de um arquivo .class Java 8. O header dot_class.h declara a struct com todos os seus campos (magic, versão, constant pool, interfaces, campos, métodos, atributos, ponteiro para superclasse). A implementação em dot_class.c cuida da alocação inicial (com todos os ponteiros nulos) e da liberação recursiva de toda a árvore de memória.
