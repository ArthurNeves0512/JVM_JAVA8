fields_interfaces.c class_loader

Leitura das seções de interfaces e campos do arquivo .class
Papel no projeto

Responsável por decodificar as seções de interfaces e campos do arquivo .class. Cada campo (field_info) contém flags de acesso, índices para nome e descritor no constant pool, e seus próprios atributos (ex: ConstantValue para constantes). As interfaces são armazenadas como simples índices no CP.
