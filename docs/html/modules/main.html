main.c main

Ponto de entrada da JVM — orquestra toda a pipeline de carregamento e execução
Papel no projeto

Este é o ponto de entrada do programa. Ele coordena toda a pipeline de execução: faz o parsing dos argumentos CLI, redireciona stdout para o arquivo de saída configurado, carrega e decodifica o arquivo .class Java 8, imprime todas as informações do ClassFile (constant pool, campos, métodos, atributos) e finalmente invoca o interpretador de bytecodes para executar o método main da classe.
