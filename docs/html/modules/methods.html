methods.c class_loader

Leitura, alocação e liberação da seção de métodos do arquivo .class
Papel no projeto

Responsável por decodificar a seção de métodos do arquivo .class. Cada method_info contém flags de acesso, índices para nome e descritor, e seus atributos — o mais crítico sendo o atributo Code que armazena os bytecodes executáveis. freeMethods é chamado por freeClassFile para limpar essa memória.
