basic_ops.c interpreter

Motor de execução de bytecodes — o grande loop de interpretação da JVM
Papel no projeto

O arquivo mais extenso do projeto. Implementa executaFrame(), o núcleo do interpretador: um while + switch que despacha todos os opcodes JVM suportados. Cobre aritmética inteira, long, float e double; load/store de variáveis locais e pilha; controle de fluxo (if, goto, tableswitch, lookupswitch); criação de objetos e arrays; acesso a campos de instância e estáticos; e despacho de chamadas de método para execInvokestatic, execInvokevirtual, execInvokespecial. Também gerencia a tabela de campos estáticos e o pool de arrays.

Os rótulos de cada case no switch usam o enum Opcode definido em opcodes.h (ex.: case OP_IADD:, case OP_IFEQ:), eliminando literais hexadecimais do código-fonte.

executaFrame()linha 218
void executaFrame(Frame *f, ClassFile *cf)

Loop principal de interpretação. A cada iteração lê o opcode no PC e executa via switch (op), cujos cases usam o enum Opcode (ex.: case OP_IADD:, case OP_IFEQ:, case OP_INVOKEVIRTUAL:). Cobre: aritmética (OP_IADD, OP_LADD, OP_FADD, OP_DADD, ...), conversões (OP_I2L, OP_D2F, ...), load/store (OP_ILOAD, OP_ASTORE, ...), arrays (OP_NEWARRAY, OP_AALOAD, OP_AASTORE, ...), controle de fluxo (OP_IFEQ, OP_GOTO, OP_TABLESWITCH, OP_LOOKUPSWITCH), criação de objetos (OP_NEW), acesso a campos (OP_GETFIELD, OP_PUTFIELD, OP_GETSTATIC, OP_PUTSTATIC), e chamadas de método (OP_INVOKESTATIC, OP_INVOKEVIRTUAL, OP_INVOKESPECIAL). 198 opcodes implementados no total.
