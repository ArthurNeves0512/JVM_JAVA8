method_invoke.c method_invoke

Implementação dos opcodes de invocação: invokestatic, invokevirtual e invokespecial.
Papel no projeto

Resolve e executa chamadas de método JVM. Para métodos do projeto, cria um Frame filho, transfere os argumentos e executa. Para métodos nativos, despacha via lookupNative(). O invokevirtual suporta polimorfismo usando o ClassFile real do objeto em runtime. O invokespecial trata construtores com lógica especial para distinguir same-class de cross-class.
