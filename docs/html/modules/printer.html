printer.c printer

Impressão do ClassFile decodificado em formato legível para humanos.
Papel no projeto

Imprime todas as seções de um ClassFile: cabeçalho geral (magic, versões, contadores), constant pool completo com resolução de referências, interfaces, campos com flags de acesso, métodos com bytecodes desassemblados (via printBytecode) e atributos de classe. A saída vai para stdout, que no fluxo normal é redirecionado para um arquivo .txt pelo main.
