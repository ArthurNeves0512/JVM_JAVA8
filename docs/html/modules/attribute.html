attribute.c types

Parser, printer e liberador de atributos JVM (Code, ConstantValue, Exceptions, etc.)
Papel no projeto

Implementa a leitura (decodificação), impressão e liberação de todos os atributos JVM suportados. O atributo mais importante é o Code, que contém os bytecodes executáveis de um método. A função getUtf8() é um utilitário crítico usado em todo o projeto para resolver strings do constant pool. Os atributos não reconhecidos são armazenados como bytes raw.

Funções
getUtf8() attribute.c
char *getUtf8(cp_info *constant_pool, u2 index)

Retorna uma cópia (strdup) da string UTF-8 na entrada index do constant pool. O chamador é responsável por liberar com free(). Retorna NULL se o índice for inválido ou a tag não for CONSTANT_Utf8.

Parâmetros

Retorno: String alocada com o conteúdo UTF-8, ou NULL
