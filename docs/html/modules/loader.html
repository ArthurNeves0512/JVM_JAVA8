loader.c class_loader

Carregador principal de arquivos .class: decodifica o formato binário e resolve herança
Papel no projeto

Coração do carregador de classes. Lê e decodifica o arquivo .class sequencialmente: magic number, versões, constant pool (com todas as 14 variantes de tag), access flags, this_class e super_class. Também carrega classes dependentes do disco em runtime (loadClassFile) e resolve recursivamente a cadeia de herança (loadSuperClass), preenchendo o campo super_class_file de cada ClassFile. O diretório base de busca é configurado por setClassDir.

loadClassFile()linha 207
ClassFile *loadClassFile(const char *filename)

Carrega um arquivo .class do disco a partir de um nome de arquivo. Primeiro busca no diretório base (g_class_dir); com fallback sem prefixo. Retorna NULL para classes nativas. Carrega recursivamente a cadeia de herança via loadSuperClass.

ClassFile *loadSuperClass(ClassFile *cf)
