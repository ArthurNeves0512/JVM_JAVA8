opcodes.c types

Tabela de opcodes, desassemblador de bytecode e cálculo de tamanho de instrução
Papel no projeto

Define a tabela estática opcode_table[256] mapeando cada bytecode JVM ao seu mnemônico e tamanho em bytes. Implementa o desassemblador de bytecode (printBytecode) que exibe cada instrução com seu offset, nome e operandos — incluindo resolução de referências do constant pool. Também calcula o tamanho correto de instruções de tamanho variável (tableswitch, lookupswitch, wide).

Funções
opcode_size_variable() linha ~190
u4 opcode_size_variable(const u1 *code, u4 pc)

Calcula o tamanho em bytes de instruções de tamanho variável: tableswitch (alinhamento + low/high + offsets), lookupswitch (alinhamento + npairs) e wide (diferente para iinc). Para outros opcodes, retorna 1 (o chamador usa opcode_table.size).

void printBytecode(const u1 *code, u4 code_length, cp_info *cp)

Desassembla e imprime o bytecode de um método: exibe o offset, mnemônico e operandos de cada instrução. Resolve referências do constant pool para instrução como invokevirtual, getstatic, new. Trata corretamente tableswitch, lookupswitch e wide.
