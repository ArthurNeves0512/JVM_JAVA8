jvm_stack.c jvm_stack

Pilha de frames de ativação da JVM — push/pop/peek com verificação de overflow.
Papel no projeto

Implementa a JVMStack: uma pilha de até 256 frames que simula a call stack da JVM. Cada chamada de método empilha um Frame; cada retorno o desempilha. Detecta stack overflow e underflow com mensagens de erro explícitas.
