interpreter.c interpreter

Ponto de entrada do interpretador de bytecodes — inicializa e executa o método main
Papel no projeto

Implementa o ponto de entrada da execução de bytecodes da JVM. A função executaJVM inicializa o registro de métodos nativos, localiza o método main no ClassFile, cria o frame de execução e inicia o loop de interpretação via executaFrame. Ao término, libera todos os recursos alocados durante a execução: arrays, campos estáticos e heap.

Funções

void executaJVM(ClassFile *cf)

Ponto de entrada do interpretador. Inicializa os métodos nativos, varre os métodos do ClassFile procurando por "main", localiza seu Code_attribute, cria o frame inicial e o executa. Ao final, libera arrays, campos estáticos e heap. Imprime erro para stderr se o método main não for encontrado.
