heap.c heap

Heap de objetos Java em runtime — alocação, busca de campos e liberação.
Papel no projeto

Implementa a heap simplificada da JVM: um pool estático de até 1024 HeapObjects. Cada objeto armazena o nome da classe, o ClassFile associado, todos os campos de instância (incluindo herdados via cadeia super_class_file) e um ponteiro native_data para classes como StringBuilder. Não há GC; a heap é liberada em bloco ao final da execução.

HeapObject *alocaObjeto(ClassFile *cf, const char *class_name)

Aloca um HeapObject na heap: copia o nome da classe, conta os campos percorrendo toda a cadeia de herança (cf→super_class_file→...), aloca e nomeia os campos com valor inicial zero. O objeto é registrado no pool estático (max 1024) para liberação posterior por liberaHeap().
