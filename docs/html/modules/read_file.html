read_file.c file

Leitura do arquivo binário .class em modo big-endian
Papel no projeto

Este módulo é responsável pela abertura do arquivo .class Java no sistema de arquivos. O arquivo read_file.c implementa a função de abertura, enquanto o header read_byte.h define funções inline para leitura de 1, 2 e 4 bytes no formato big-endian exigido pela especificação JVM. Essas primitivas (u1Read, u2Read, u4Read) são utilizadas por todo o módulo class_loader para desserializar os dados do arquivo.

Funções
readFile() linha 4
FILE *readFile(const char *file_path)

Abre o arquivo .class em modo binário de leitura ("rb"). Encerra o processo com perror se o arquivo não puder ser aberto.

Lê 2 bytes em big-endian e retorna como u2 (uint16_t). O byte mais significativo é lido primeiro.

Retorno: Valor de 2 bytes em big-endian como u2
