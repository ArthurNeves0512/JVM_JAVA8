JVM Java 8 em C Documentação

Implementação de uma Java Virtual Machine em C — interpretador de bytecodes Java 8 (.class).
Sobre o projeto

Este projeto implementa uma JVM simplificada em C, capaz de carregar arquivos .class no formato Java 8 (major version 52), decodificar o constant pool, campos, métodos e atributos, imprimir as informações do ClassFile, e executar o bytecode do método main incluindo operações aritméticas, controle de fluxo, arrays, objetos, herança e métodos nativos simulados (System.out.println, StringBuilder, String.valueOf, etc.).

Pipeline de execução
1
Argumentos CLI — parse_args() extrai o caminho do .class e opções
2
Leitura binária — readFile() abre o arquivo .class em modo binário
3
Decodificação — o class_loader lê sequencialmente: magic, versão, constant pool, flags, campos, métodos, atributos
4
Impressão — o printer exibe o ClassFile decodificado em formato legível (saída para .txt)
5
Execução — executaJVM() localiza o método main, cria um Frame e inicia o loop de bytecodes
6
Liberação — arrays, campos estáticos, heap e ClassFile são liberados
